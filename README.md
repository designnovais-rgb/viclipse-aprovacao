# VIclipse — aprovação de cortes

Site: https://designnovais-rgb.github.io/viclipse-aprovacao/

Assista, edite (texto do vídeo, título, legenda, hashtags, início e fim) e clique em **Aprovar e postar**. O pedido vira uma issue; o workflow `Aprovar e postar corte` aplica as edições com ffmpeg, posta pelo Zernio (Instagram + YouTube Shorts) e atualiza `catalog.json`.
Os vídeos ficam na release `cortes`. Só pedidos abertos pelo dono do repositório são processados.
